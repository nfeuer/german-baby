# 📖 German Baby Learning App - User Guide

Welcome to the German Baby Learning App! This guide will help you make the most of all features.

---

## 🎯 Quick Start

1. **Select your baby's age** using the month range buttons at the top
2. **Browse phrases** organized by developmental stage
3. **Click any card** to flip and see the German translation
4. **Star favorites** ⭐ for quick access
5. **Mark learned** ✅ to track progress
6. **Toggle to lullabies** 🎵 for bedtime songs

---

## 📱 Main Features

### 🗓️ Month Selector

Choose your baby's current age range to see age-appropriate content:

- **0-3 months** - Newborn basics (greetings, comfort, feeding)
- **3-6 months** - Early interaction (playing, emotions, body parts)
- **6-9 months** - Expanding vocabulary (foods, objects, animals)
- **9-12 months** - Active learning (actions, requests, more complex phrases)
- **12-15 months** - Walking and talking (movement, independence)
- **15-18 months** - Conversations (questions, descriptions)
- **18-21 months** - Advanced concepts (colors, numbers, relationships)
- **21-24 months** - Full sentences and complex ideas

**How it works:**
- Selecting a month range shows all phrases appropriate for that age and younger
- Example: Select "6-9 months" to see phrases for 0-9 month olds

## 🎴 Phrase Cards

### Front of Card (English)
- **English phrase** - What you'll say to your baby
- **Topic icon** - Visual category indicator
- **Context** - When to use this phrase
- **Action buttons:**
  - ⭐/**☆** - Favorite/unfavorite
  - ✅/**⬜** - Mark learned/unlearned
  - 🗑️ - Hide phrase (delete)

### Back of Card (German)
- **German translation** - The phrase in German
- **Pronunciation guide** - How to say it phonetically
- **English reference** - English version at bottom
- **Related vocabulary** (when available) - Additional words to learn
- **Topic icon** - Reminds you of the category

### How to Use Cards

**Flipping:**
- Click anywhere on the card to flip
- Click again to flip back
- Smooth 3D animation

**Favoriting:**
- Click the ⭐ to mark as favorite
- Use "Show Favorites" button to see only starred phrases
- Perfect for phrases you're actively working on

**Marking Learned:**
- Click ✅ when you've mastered a phrase
- Progress bar shows your learning journey
- Helps track which phrases to focus on

**Hiding Phrases:**
- Click 🗑️ to hide phrases you don't want to use
- Use "Show Deleted" button to restore hidden phrases
- Keeps your learning focused

- **Eating** 🍎 - Meals, foods, drinks
- **Playing** 🎮 - Toys, games, activities

- **Colors** 🎨 - Colors and shapes
- **Numbers** 🔢 - Counting, quantities
- **Animals** 🐶 - Pets, farm animals, sounds

- **Hygiene** 🛁 - Bath, potty, grooming

**How to use:**
- Click a topic to show only those phrases
- Click multiple topics to see all selected

**Search functionality:**
- Type in English or German
- Real-time filtering as you type
- Case-insensitive matching
- Searches both phrase and translation

**Examples:**
- Search "apple" - finds eating phrases about apples
- Search "schlafen" - finds sleep-related phrases
- Search "good morning" - finds morning greetings

### Filter Buttons

**⭐ Show Favorites:**
- Toggle to show only starred phrases
- Great for daily practice
- Shows count of favorites

**🗑️ Show Deleted:**
- View all hidden phrases
- Click 🗑️ again to restore phrases
- Manage your curated phrase list

**🎵 Show Lullabies:**
- Switch between phrases and lullabies
- Same month and topic filters apply
- Shows count of available lullabies

## 📊 Progress Tracking

### Progress Bar
- Located near the top of the page
- Shows: "X of Y phrases learned (Z%)"
- Visual green bar fills as you learn
- Only counts phrases for selected month range

### Persistence
All your progress is automatically saved:
- ⭐ Favorites
- ✅ Learned phrases
- 🗑️ Deleted/hidden phrases
- 🗓️ Last selected month (future feature)
- Saved to browser localStorage
- Works offline
- Persists across sessions

**Note:** Progress is saved per browser/device. If you clear browser data, progress will be lost.

## 🗣️ How to Practice

### Daily Routine Integration

**Morning:**
1. Select "Greetings" topic
2. Practice "Good morning" (Guten Morgen)
3. Flip card to see pronunciation
4. Star it for tomorrow

**Feeding Time:**
1. Select "Eating" topic
2. Find phrases for current meal
3. Use related vocabulary for foods
4. Example: "Did the apple taste good?" → shows banana, pear, strawberry

**Playtime:**
1. Select "Playing" or "Animals" topic
2. Filter by baby's current age
3. Practice relevant phrases
4. Mark learned when comfortable

**Bedtime:**
1. Click "🎵 Show Lullabies"
2. Select "Sleep" topic
3. Choose a lullaby
4. Follow pronunciation guide
5. Sing to your baby

### Learning Strategy

**Week 1-2: Basics**
- Focus on greetings and sleep
- Master 5-10 essential phrases
- Use favorites system

**Week 3-4: Expansion**
- Add eating and playing topics
- Learn related vocabulary
- Practice daily routines

**Month 2+: Consistency**
- Review learned phrases
- Add new topics gradually
- Use search to find specific phrases
- Hide phrases you don't need

**Age Progression:**
- Update month selector as baby grows
- New phrases unlock automatically
- Revisit old phrases with new context

## 🎯 Pro Tips

### 💡 Learning Tips

1. **Start small** - Don't try to learn everything at once
2. **Be consistent** - Use the same phrases daily
3. **Repeat often** - Babies learn through repetition
4. **Use gestures** - Combine German words with actions
5. **Don't stress pronunciation** - Close enough works! Babies are forgiving
6. **Make it fun** - Use animated voice and expressions
7. **Context matters** - Use phrases at the right moments

### 🔧 App Tips

1. **Favorite liberally** - Star phrases you want to focus on this week
2. **Hide irrelevant** - Delete phrases that don't fit your lifestyle
3. **Use related vocab** - Check card backs for bonus words
4. **Filter by topic** - Focus learning on one area at a time
5. **Track progress** - Mark phrases learned to stay motivated
6. **Install as PWA** - Add to phone for offline access
7. **Search is powerful** - Find specific phrases quickly

### 📱 Mobile Tips

1. **Install to home screen** - See INSTALL-ON-PHONE.md
2. **Use offline** - Works in airplane mode
3. **Landscape mode** - Cards display well both ways
4. **One-handed use** - Large tap targets
5. **Quick access** - Keep app on main home screen

## ❓ Common Questions

**Q: Do I need to be fluent in German?**
A: No! This app is designed for English speakers learning German.

**Q: Will my baby become fluent?**
A: This gives exposure to German sounds and words. For fluency, consistent practice and immersion are needed.

**Q: Can I use this offline?**
A: Yes! After installing as a PWA, everything works offline.

**Q: How do I install on my phone?**
A: See INSTALL-ON-PHONE.md for detailed instructions.

**Q: What if I don't like the pronunciation guide?**
A: The guides are simplified. For precise pronunciation, consider using an online German pronunciation tool.

**Q: Can I add my own phrases?**
A: Currently no, but this is a planned feature. For now, you can edit the JSON files directly.

**Q: Do the lullabies have audio?**
A: Not yet - this is a future feature. Use the pronunciation guide to learn the melody online first.

**Q: What age is this app for?**
A: 0-24 months, but phrases work for older toddlers too!

**Q: Does it sync across devices?**
A: Not yet - progress is saved per device. Export/import is a planned feature.

## 🆘 Troubleshooting

**Cards won't flip:**
- Refresh the page
- Check that JavaScript is enabled
- Try a different browser

**Progress not saving:**
- Check browser localStorage isn't disabled
- Don't use private/incognito mode
- Check browser settings allow storage

**Search not working:**
- Clear search box and try again
- Check spelling
- Try searching in the other language

**Filters showing no results:**
- Check month selector - increase age range
- Deselect topic filters
- Clear search box

**App won't install:**
- See INSTALL-ON-PHONE.md troubleshooting section
- Check you're using supported browser
- Make sure icons are generated (see ICON-SETUP.md)
